AI assistance

Ten advisory agents on IBM watsonx Orchestrate

Request classifier

Reads the letter and suggests template, activity and urgency.

Pack checker

Finds gaps in a draft tender pack before approval.

Notice drafter

Drafts the gazette and CAPT notices in Arabic and English.

Relevance matcher

Matches eligible vendors and tenders.

Clarification assistant

Drafts cited answers to bidder questions.

Compliance screener

Checks opened bids against required documents.

Evaluation narrator

Writes the committee's evaluation narrative.

Grade reviewer

Reviews vendor documents against grade criteria.

Document intelligence

Classifies uploads and extracts key fields.

TenderFlow assistant

Supervisor agent: answers in context and routes to the specialists.

🧑‍⚖️ Advisory only — a person decides
🔒 Never sees bid contents before opening
🧾 Every AI run is recorded in the audit trail

Agents are packaged for import into the customer's watsonx Orchestrate instance. Next: an admin agent that turns plain-language requests into draft templates and rules for human approval.
